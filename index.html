Release notes & checksum ↗

Start with a sample document.

  1. Download and extract the entire ZIP.
  2. Open MetaClean.exe inside the MetaClean folder. Keep _internal beside it.
  3. Try the desktop workflow with a trusted copy of a document. Review the output.

No Python installation needed. This is an unsigned preview; Windows may flag an unknown publisher. Only run software you trust.

Read the preview limitations

Use trusted files. PDF parsing is not isolated with enforced memory or time limits, so a malformed document could hang or exhaust the app. Legacy command-line output handling can overwrite files; use the desktop workflow.

Metadata cleanup is not full anonymization or malware scanning. Comments, macros, embedded files, and visible identifying content can remain. Writing changes need human review.
