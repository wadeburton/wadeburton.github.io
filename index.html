File Organizer.

in its place.

Turn a crowded folder into a clear plan. Group files, inspect their next destination, and organize them from a native desktop workspace with a local undo journal.

01

Five ways to organize

Group by category, extension, timeline, smart topic, or category and year. Edit category names, folder rules, and colors in the app.

02

Preview-bound moves

Select the files and confirm the exact destinations. Stale previews are rejected, and Windows moves refuse occupied names.

03

Undo with checks

A local journal records each move. Undo verifies file identity and SHA-256 before restoring it; changed files and name conflicts stay untouched.

FROM BROWSER TOOL TO DESKTOP APP

A stronger foundation.

Direct local operations.
No browser server or file-opening API.

The desktop version separates the interface, rules, and file operations. Background workers handle folder previews and moves. Interrupted journal entries are reconciled without automatically moving files; ambiguous cases are marked for manual review.

Test coverage includes grouping modes, stale previews, collision handling, modified-file undo, simulated journal failures, UI selection, and a synthetic move-and-undo smoke test. The skipped symbolic-link test requires additional Windows privileges.

File Organizer 1.0.0 · Windows x64 · Portable ZIP

Download Windows preview ↓

Release notes & checksum ↗

Try it on a sample folder first.

  1. Extract the entire ZIP. Open FileOrganizer.exe and keep _internal beside it.
  2. Choose a local folder, review the proposed moves, then confirm.
  3. Use Activity & undo to restore unchanged files when needed.

No Python installation required. This unsigned preview moves files; keep backups and only run software you trust.

Read the preview limitations

Windows local folders only, up to 5,000 entries. Network shares, linked files, reparse points, and some cloud placeholders are unsupported. Avoid active sync folders. It is not a backup tool or a defense against malicious concurrent filesystem changes.

Activity stays on this computer and contains paths and file hashes. Original browser-app history is not imported. Category colors are shown in the app; this preview does not recolor Windows Explorer folders. Undo leaves empty folders in place.
